# SLFF Trgovina (shop.slff.eu) del 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working shop on shop.slff.eu: catalog, product variants with stock, cart, Stripe Checkout (EU-27, Stripe Tax, Pošta Slovenije shipping rates), stock reservation, paid orders via webhook, confirmation/shipping mail, admin for packing and catalog, legal pages.

**Architecture:** New closed schema `trgovina` (not exposed to the API) with security-definer RPCs; anon reads the catalog through `trgovina_katalog()`/`trgovina_izdelek(slug)`; Edge Function `trgovina-nakup` validates the cart, reserves stock and creates the Checkout session; `stripe-webhook` gets a `slff-shop` branch that marks orders paid / releases reservations; `trgovina-posta` sends mail. Separate Vite app `shop/` (like `scout/`) with customer pages and `/admin`.

**Tech Stack:** PostgreSQL (Supabase self-hosted), Deno Edge Functions, Stripe REST, nodemailer (Mailcow), React + TS + Tailwind (Vite).

**Spec:** `docs/superpowers/specs/2026-10-18-trgovina-design.md`

**Files:**

**Interfaces (Produces):**
- Tables in schema `trgovina`:
  - `izdelki(id bigint identity pk, slug text unique not null check (slug ~ '^[a-z0-9-]+$'), ime_sl text not null, ime_en text not null, opis_sl text not null default '', opis_en text not null default '', kategorija text not null check (kategorija in ('oblacila','dodatki','dom','nalepke')), slike text[] not null default '{}', tax_code text not null default 'txcd_99999999', pismo boolean not null default false, aktiven boolean not null default false, vrstni_red int not null default 0, created_at timestamptz default now())`
  - `razlicice(id bigint identity pk, izdelek_id bigint not null references trgovina.izdelki on delete cascade, oznaka_sl text not null, oznaka_en text not null, sku text unique not null, cena int not null check (cena > 0), zaloga int not null default 0 check (zaloga >= 0), teza_g int not null default 0, aktivna boolean not null default true, vrstni_red int not null default 0)`
  - `narocila(id bigint identity pk, javna_oznaka text unique not null default upper(substr(md5(gen_random_uuid()::text),1,8)), stanje text not null default 'caka_placilo' check (stanje in ('caka_placilo','placano','poslano','preklicano','vrnjeno','poteklo')), user_id uuid references auth.users on delete set null, email text, ime text, naslov jsonb, jezik text not null default 'sl' check (jezik in ('sl','en')), znesek_postavke int, znesek_dostava int, znesek_ddv int, znesek_skupaj int, dostava_kljuc text, stripe_checkout_id text unique, stripe_payment_intent text, sledilna text, rezervirano_do timestamptz not null default now() + interval '30 minutes', placano_at timestamptz, poslano_at timestamptz, created_at timestamptz not null default now())`
  - `postavke(id bigint identity pk, narocilo_id bigint not null references trgovina.narocila on delete cascade, razlicica_id bigint not null references trgovina.razlicice, ime text not null, cena int not null, kolicina int not null check (kolicina between 1 and 20))`
  - Reservation = `postavke` of orders with `stanje = 'caka_placilo' and rezervirano_do > now()`. Available = `zaloga − sum(reserved kolicina)`.
- Functions:
  - `public.trgovina_katalog() returns jsonb` (anon, authenticated): active products with active variants: `[{slug, ime_sl, ime_en, kategorija, slike, cena_od, na_voljo}]` where `na_voljo` is `'da'|'malo'|'ne'` (malo = 1–3 available across variants), sorted by `vrstni_red, id`. Never returns stock numbers.
  - `public.trgovina_izdelek(p_slug text) returns jsonb` (anon, authenticated): product + variants `[{id, oznaka_sl, oznaka_en, cena, na_voljo}]` or null if inactive/unknown.
  - `trgovina.rezerviraj(p_postavke jsonb, p_user uuid, p_jezik text) returns jsonb` (service_role only; called by Edge Function): input `[{razlicica_id, kolicina}]` (1–20 lines, each 1–20, total ≤ 50); locks the variants (`for update`, ordered by id to avoid deadlocks), checks active product+variant and availability, creates `narocila` row (`caka_placilo`) + `postavke` with current name/price; returns `{narocilo_id, javna_oznaka, postavke:[{ime, cena, kolicina, tax_code}], pismo: bool (all items pismo)}`. On shortage raises `exception 'Trgovina: ni dovolj zaloge.' using hint = 'trgovina-zaloga'`; invalid input hint `'trgovina-vnos'`.
  - `trgovina.vezi_sejo(p_narocilo bigint, p_checkout text)` (service_role): stores the Stripe session id.
  - `trgovina.iz_placila(p_checkout text, p_payment_intent text, p_email text, p_ime text, p_naslov jsonb, p_postavke int, p_dostava int, p_ddv int, p_skupaj int, p_dostava_kljuc text) returns text` (service_role): idempotent: if already `placano`/`poslano` → `'ze'`; if `caka_placilo` (even if reservation expired) → decrement `zaloga` by quantities (clamped at 0 with a Discord-worthy note returned as `'premalo'` if stock would go negative), set paid fields, `placano_at=now()`, return `'placano'`; unknown → `'neznano'`.
  - `trgovina.potekla(p_checkout text) returns text` (service_role): `caka_placilo` → `poteklo`.
  - Admin (authenticated, check `is_admin()` else `insufficient_privilege`): `public.trgovina_admin_narocila(p_stanje text default 'placano') returns jsonb`, `public.trgovina_admin_poslano(p_narocilo bigint, p_sledilna text) returns jsonb` (sets `poslano`, returns `{email, jezik, javna_oznaka, sledilna, ime}` for the mail), `public.trgovina_admin_izdelki() returns jsonb` (all products + variants incl. stock), `public.trgovina_admin_shrani_izdelek(p jsonb) returns bigint` (insert/update product by id), `public.trgovina_admin_shrani_razlicico(p jsonb) returns bigint`.
  - `public.trgovina_moja_narocila() returns jsonb` (authenticated): caller's orders (not `caka_placilo`/`poteklo`) with items.
- Storage: bucket `trgovina` public read; write only admins (policy on `storage.objects` with `bucket_id = 'trgovina' and is_admin()`); guard with `if to_regclass('storage.objects') is not null` as in `20261012091100_prevzem_igralca.sql`.
